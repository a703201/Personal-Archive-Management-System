## 1. 设计原则与取向

### 1.1 为什么参考苹果设计语言

AMS 的用户画像里，大量是"技术不敏感但对体验敏感"的普通用户，且档案管理本质是**低频、慢思考、高信任**的场景。苹果设计语言在这三点上契合：

| 苹果设计的特征 | 在 AMS 中的价值 |
| --- | --- |
| **留白与层次** | 档案条目密度高，清晰的层次让"信息多"不显得"乱" |
| **克制的动效** | 档案是严肃数据，动效过盛会削弱可信度 |
| **材质与深度** | 半透明层让"浮层在上、内容在下"的空间关系一眼可辨 |
| **即时反馈** | 保存/上传/删除的即时响应，建立"系统可靠"的感知 |
| **深浅色自适应** | 长时间整理档案的舒适度；夜间查看证件照片尤其重要 |

### 1.2 八条设计原则在本项目中的具体化

| 苹果原则 | AMS 中的落地 |
| --- | --- |
| **Purpose 有目的** | 每屏只回答一个主要问题。档案列表屏只回答"我的档案有哪些"，不混入统计图表 |
| **Agency 掌控感** | 删除可撤销（30 天回收站）；危险操作二次确认；用户随时可见"当前以谁的身份/对谁操作" |
| **Responsibility 责任** | 敏感字段默认掩码，展开需二次确认并留痕；导出需明确告知范围 |
| **Familiarity 熟悉性** | 沿用通用隐喻：垃圾桶=删除、锁=加密、标签=分类、时钟=历史；不发明新图标语言 |
| **Flexibility 灵活性** | 分类可自定义、字段可自定义、布局可折叠；深浅色跟随系统 |
| **Simplicity 简洁** | 表单按分类模板动态渲染，只显示该分类的字段；高级选项收进"展开" |
| **Craft 精致** | 间距、字号、动效参数全部令牌化，不留"差不多"的值 |
| **Delight 愉悦** | 克制的愉悦：上传完成的一次轻微回弹、搜索命中时的高亮呼吸。不做庆祝动画 |

### 1.3 明确不做的事

| 不做 | 原因 |
| --- | --- |
| 大面积渐变、玻璃拟态堆叠 | 与"严肃档案"气质冲突；多层半透明会导致对比度崩塌 |
| 弹跳、旋转、粒子等夸张动效 | 削弱专业感与可信度 |
| 纯装饰性插画 | 增加噪音 |
| 跟随鼠标的磁性按钮 | 干扰精确操作 |
| 骨架屏以外的加载占位图 | 骨架屏已足够 |

## 2. 设计令牌

### 2.1 令牌分层

```
① 基础令牌（Primitive）—— 原始值，不可直接使用
   --gray-0 … --gray-950, --blue-500, --space-1 … --space-8
        ↓
② 语义令牌（Semantic）—— 用途绑定，组件只允许使用这一层
   --color-bg, --color-surface, --color-text-primary, --color-accent …
        ↓
③ 组件令牌（Component）—— 组件级微调（可选）
   --button-primary-bg, --card-radius …
```

**硬性规则**：组件样式**只能**引用语义令牌或组件令牌，禁止直接引用基础令牌。这样换主题只需替换语义层的值。

### 2.3 首屏防闪烁

```html
<!-- index.html <head> 内联，必须在 CSS 之后、渲染之前 -->
<script>
  (function () {
    var t = localStorage.getItem('ams.theme')
    var m = window.matchMedia('(prefers-color-scheme: dark)').matches
    var theme = t === 'light' || t === 'dark' ? t : (m ? 'dark' : 'light')
    document.documentElement.setAttribute('data-theme', theme)
  })()
</script>
```

> 主题脚本必须**同步内联**在 `<head>`。任何异步加载都会导致刷新时的白屏闪烁（FOUC）。

## 3. 色彩系统

### 3.1 语义色映射表

| 语义令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--color-bg` | `#ffffff` | `#0a0a0b` | 页面底色 |
| `--color-surface` | `#ffffff` | `#141416` | 卡片/面板底色 |
| `--color-surface-raised` | `#ffffff` | `#1c1c1e` | 浮起层（弹层、Sheet） |
| `--color-surface-sunken` | `#f5f5f7` | `#0a0a0b` | 凹陷区（输入框底、代码块） |
| `--color-text-primary` | `#141416` | `rgba(255,255,255,.92)` | 主文本 |
| `--color-text-secondary` | `#6e6e73` | `rgba(235,235,245,.60)` | 次要说明 |
| `--color-text-tertiary` | `#8e8e93` | `rgba(235,235,245,.32)` | 占位符、禁用 |
| `--color-separator` | `rgba(0,0,0,.10)` | `rgba(255,255,255,.12)` | 分隔线 |
| `--color-accent` | `#0071e3` | `#64a8ff` | 主操作、选中态、链接 |
| `--color-accent-soft` | `#d6e9ff` | `rgba(100,168,255,.16)` | 选中背景、轻提示底 |
| `--color-danger` | `#ff3b30` | `#ff6961` | 删除、错误、L4 高敏标记 |
| `--color-warning` | `#ff9500` | `#ffa940` | 到期提醒、需注意 |
| `--color-success` | `#34c759` | `#4cd964` | 已归档、校验通过 |
| `--color-info` | `#30b0c7` | `#66d4e6` | 信息提示 |

### 3.2 敏感度色彩语义

| 敏感度 | 标记色 | 用法 |
| --- | --- | --- |
| L1 公开 / L2 内部 | 无标记 | 不加视觉噪声 |
| L3 敏感 | `--color-warning` | 分类图标旁小圆点 + 列表中的锁形图标 |
| L4 高敏 | `--color-danger` | 卡片左侧 2px 竖条 + "高敏" 文字标签 |

> **原则**：敏感度用**形状 + 位置**（图标、竖条）表达，颜色只作辅助。色觉障碍用户仍能识别。

### 3.3 分类色（11 类）

分类用**低饱和度**色调区分，避免彩色块喧宾夺主（分类清单与 `06-数据模型设计.md` §12.3 一致）：

| 分类 | 色相 | 分类 | 色相 |
| --- | --- | --- | --- |
| 基本信息 | 灰蓝 | 家庭关系 | 粉紫 |
| 证件信息 | 蓝 | 健康信息 | 红 |
| 教育经历 | 青绿 | 资产信息 | 金 |
| 职业经历 | 靛蓝 | 影像附件 | 中性灰 |
| 资质证书 | 紫 | 联系方式 | 绿 |
| | | 自定义 | 随机分配 |

用法：仅在分类图标底色与分类页的强调色中使用，**不做大面积填充**。

### 3.4 对比度要求（WCAG）

| 内容 | 最低对比度 |
| --- | --- |
| 正文与背景 | 4.5:1（AA） |
| 大字号（≥18.66px 粗体 / ≥24px） | 3:1（AA Large） |
| 图标、边框、焦点环 | 3:1（AA Non-text） |
| 禁用态文本 | 3:1（若仍需可读） |

> 特别检查：`--color-text-secondary` 在 `--color-surface-grouped` 背景上的对比度（浅色下约 4.6:1，深色下约 5.4:1，均达标）。

## 4. 排版系统

### 4.1 字号与语义

| 令牌 | 字号 | 行高 | 字重 | 字距 | 用途 |
| --- | --- | --- | --- | --- | --- |
| `--font-size-caption2` | 11px | 14px | 500 | +0.06em | 标签、状态徽章 |
| `--font-size-caption` | 12px | 16px | 400 | 0 | 辅助说明、时间戳 |
| `--font-size-footnote` | 13px | 18px | 400 | 0 | 次要信息、表格次要列 |
| `--font-size-subhead` | 15px | 20px | 400 | 0 | 列表副标题、表单说明 |
| `--font-size-body` | 17px | 24px | 400 | 0 | **正文默认** |
| `--font-size-headline` | 17px | 22px | 600 | 0 | 列表主标题、导航标题 |
| `--font-size-title3` | 20px | 25px | 600 | -0.01em | 卡片区标题 |
| `--font-size-title2` | 22px | 28px | 600 | -0.012em | 页面标题 |
| `--font-size-title1` | 28px | 34px | 700 | -0.016em | 大标题、空状态主文案 |
| `--font-size-large` | 34px | 41px | 700 | -0.02em | 数字统计 |

### 4.2 字距（tracking）规则

**字号越大，字距越紧** —— 这是苹果排版的核心原则，也是最常被忽略的：

```
大字（≥28px）：letter-spacing: -0.016em ~ -0.02em   ← 收紧
中字（17–22px）：-0.01em ~ -0.012em                ← 轻微收紧
正文（15–17px）：0                                 ← 不动
小字（≤13px）：+0.02em ~ +0.06em                   ← 放宽，提升小字可读性
```

> **禁止**使用全局固定字距。一个 `letter-spacing: 0.5px` 在小字上是改善，在大标题上就是错误。

### 4.3 中文排版细则

| 项 | 规范 |
| --- | --- |
| 字体栈 | `system-ui` 优先（自带光学尺寸），回落 PingFang SC（macOS/iOS）、Microsoft YaHei（Windows）、Noto Sans CJK SC（Linux） |
| 行高 | 中文正文比西文需要更大行高 → body 24px/17px ≈ 1.41；密集列表用 20px/15px ≈ 1.33 |
| 字距 | 中文不额外加字距（保持 0），靠字号分层 |
| 断行 | `line-break: strict`；避免标点行首（`text-wrap: pretty` 或手动） |
| 数字与单位 | 数字用 `font-variant-numeric: tabular-nums`（表格对齐） |
| 中英混排 | 中西文之间不手动加空格（由排版引擎处理） |
| 长文本 | 备注类字段 `line-height: 1.5`，最大 6 行后折叠 + "展开" |

### 4.4 数字与等宽

- 金额、证件号（掩码态）、日期对齐处：`font-variant-numeric: tabular-nums`
- 证件号/SM3 指纹/存储键：等宽字体 `--font-family-mono`，字号降 1px
- 大数字统计：使用 `--font-size-large` + 字重 700 + `-0.02em` 字距

## 5. 间距、圆角、阴影

### 5.1 间距体系

4pt 基准：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`

| 场景 | 间距 |
| --- | --- |
| 图标与文字 | 6–8px |
| 表单标签与输入框 | 6px |
| 表单控件之间 | 16px |
| 卡片内边距 | 16px（紧凑）/ 20px（标准） |
| 卡片之间 | 12–16px |
| 区块之间 | 24–32px |
| 页面左右边距 | 16px（移动）/ 24px（平板）/ 32px（桌面） |
| 段落之间 | 12px |

> **规则**：只用体系内的值。`padding: 17px` 这类"差不多"的值是精致感的天敌。

### 5.2 圆角

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | 6px | 标签、徽章、小按钮、内联元素 |
| `--radius-md` | 10px | 输入框、按钮、菜单项 |
| `--radius-lg` | 14px | 卡片 |
| `--radius-xl` | 20px | Sheet、大面板 |
| `--radius-full` | 999px | 头像、圆形按钮、进度条 |

**层级规则**：容器圆角 = 内含元素圆角 + 4px（至少）。卡片 14px 内的头像用 `--radius-full`（18px）不冲突；卡片内的缩略图用 8px（介于 sm 与 md）。

### 5.3 阴影（层次表达）

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--shadow-card` | `0 1px 2px rgba(0,0,0,.04), 0 4px 16px rgba(0,0,0,.06)` | 更强 | 卡片（静态） |
| `--shadow-pop` | `0 8px 32px rgba(0,0,0,.12), 0 2px 8px rgba(0,0,0,.06)` | 更强 | 弹出菜单、气泡 |
| `--shadow-sheet` | `0 -1px 24px rgba(0,0,0,.10)` | 更强 | 底部 Sheet |

**原则**：
- **深色模式阴影要更强**（深色背景上阴影视觉衰减），因此深色令牌使用更大的不透明度
- 阴影表达**高度**，不表达"重要"。重要性用颜色与排版表达
- 浮起层（Popover）除了阴影，还应有 1px 边框或材质区分

## 6. 材质与层次

### 6.1 材质（Material）层级

| 层级 | 材质 | 模糊 | 背景 | 用法 |
| --- | --- | --- | --- | --- |
| L0 背景层 | 无 | — | `--color-bg` | 页面底 |
| L1 内容层 | 无（不透明） | — | `--color-surface` | 卡片、列表行 |
| L2 结构层 | 半透明 | `blur(20px) saturate(180%)` | `--material-sidebar` | 侧边栏 |
| L3 悬浮层 | 半透明 | `blur(30px) saturate(180%)` | `--material-toolbar` | 顶栏、底部工具栏 |
| L4 模态层 | 近不透明 | `blur(40px)` | `--material-sheet` | Sheet、对话框 |
| 遮罩 | — | — | `--material-scrim` | 模态遮罩 |

### 6.2 半透明层实现

```css
.toolbar {
  position: sticky;
  top: 0;
  z-index: 100;
  background: var(--material-toolbar);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border-bottom: 1px solid var(--color-separator);
  transition: background-color 200ms ease, border-color 200ms ease;
}

/* 滚动边缘：内容与浮动层交界处用渐隐而非硬分隔线 */
.scroll-edge {
  mask-image: linear-gradient(to bottom, transparent 0, black 12px);
}
```

**关键规则**：
1. **不要**在浅色半透明层上再叠浅色半透明层 —— 可读性会崩塌
2. 半透明层内的文本使用**高对比 + 稍重字重 + 微字距**，不用灰色
3. 半透明层内的内容**在其下方滚动**（不是不透明条带占用固定空间）
4. `prefers-reduced-transparency: reduce` 时把背景改为不透明、去掉模糊

### 6.3 滚动边缘效果

## 8. 动效规范

### 8.1 核心原则

> **动效从"当前屏幕上的值"出发，继承速度，可随时被打断。**

这意味着：
- 手势驱动的动画**必须**用弹簧（spring），不能用固定时长的 CSS transition
- 打断时从**当前呈现值**继续，不是从目标值跳
- 弹簧参数只有两个：**阻尼比（damping）** 与 **响应时间（response）**

### 8.2 弹簧参数表

| 场景 | damping | response | 说明 |
| --- | --- | --- | --- |
| 列表项重排 | 1.0 | 0.4 | 无过冲 |
| 卡片展开/收起 | 1.0 | 0.35 | 无过冲 |
| 面板推入（Sheet 打开） | 0.8 | 0.3 | 轻微过冲 |
| 页面切换（slide） | 1.0 | 0.35 | 无过冲 |
| 拖拽释放（flick） | 0.8 | 0.3 | 有动量，允许过冲 |
| 按钮按下回弹 | 0.7 | 0.2 | 快速回弹 |
| Toast 进出 | 1.0 | 0.3 | 无过冲 |
| 数字变化 | 1.0 | 0.4 | 无过冲 |

**默认规则**：绝大多数动效用 `damping: 1.0`（临界阻尼，无过冲）。**只有手势本身携带动量时**（甩动、拖拽释放）才用 `damping ≈ 0.8`。

### 8.3 动效实现

```ts
// ✅ 手势驱动：弹簧 + 速度传递（Vue 3 使用 motion-v 包）
import { useMotionValue, useSpring, useVelocity, animate } from 'motion-v'

// 面板拖拽：1:1 跟手
const x = useMotionValue(0)
const smoothX = useSpring(x, { stiffness: 320, damping: 32, mass: 0.8 })
const xVelocity = useVelocity(x)          // 实时速度（px/s）

function onPointerMove(e: PointerEvent) {
  x.set(e.clientX - startX)                // 直接跟手，不是动画
}

function onPointerUp() {
  const velocity = xVelocity.get()         // px/s
  const projected = x.get() + project(velocity)   // 动量投影
  const target = projected > width * 0.5 ? width : 0
  animate(x, target, {
    type: 'spring',
    stiffness: 320,
    damping: 28,
    mass: 0.8,
    velocity,                               // 速度交接，避免"砖墙"感
  })
}

// 动量投影（Apple 的做法）
function project(initialVelocity: number, decelerationRate = 0.998) {
  return (initialVelocity / 1000) * decelerationRate / (1 - decelerationRate)
}
```

> **API 对照说明（易踩坑）**：
> - Vue 3 用 **`motion-v`** 包（`npm i motion-v`）；`motion` 包是 React / 原生 JS 版本，Vue 里 `import { motion } from 'motion-v'`。
> - Motion 的 spring 参数是 **`stiffness` / `damping` / `mass`**（或 `bounce` + `duration`），**没有** `response` 选项。`damping`/`response` 是苹果内部的设计参数表述，用于**沟通设计意图**（如"阻尼比 1.0、响应 0.3 秒"），落到代码时需按下表换算。
> - `useMotionValue` 的值绕过 Vue 响应式系统（不触发组件重渲染），高频动画**必须**用它，不要用 `ref` 驱动 transform。
> - `useVelocity` 提供的速度用于释放时做动量交接；`animate()` 的 `velocity` 选项单位是 px/s。

**苹果参数 → Motion 参数换算表**（工程落地用）：

| 场景 | 苹果表述（设计语言） | Motion 实现 | 效果 |
| --- | --- | --- | --- |
| 列表重排 / 卡片展开 | damping 1.0, response 0.4 | `stiffness: 260, damping: 30, mass: 1` | 临界阻尼，无过冲 |
| 面板推入（Sheet） | damping 0.8, response 0.3 | `stiffness: 340, damping: 26, mass: 0.9` | 轻微过冲 |
| 拖拽释放（flick） | damping 0.8, response 0.3 | 同上 + 传入 `velocity` | 有动量，允许过冲 |
| 按钮按下回弹 | damping 0.7, response 0.2 | `stiffness: 500, damping: 22, mass: 0.6` | 快速回弹 |
| Toast 进出 | damping 1.0, response 0.3 | `stiffness: 300, damping: 32, mass: 1` | 无过冲 |

> 换算原则：**damping 越大越接近临界阻尼（越少过冲）**；**stiffness 越大响应越快**；**mass 越大越"沉"**。临界阻尼的大致关系是 `damping ≈ 2 × √(stiffness × mass)`，可据此微调。

```css
/* ✅ 非手势类：轻量 CSS 过渡足够（hover、颜色、透明度） */
.button {
  transition: background-color 150ms ease-out, transform 100ms ease-out;
}
.button:active { transform: scale(0.97); }

/* ❌ 手势驱动用 CSS transition：无法中途接管、无法速度传递 */
.panel { transition: transform 300ms ease; }   /* 用于手势 → 禁止 */
```

### 8.4 反馈时机

| 反馈 | 触发时机 | 实现 |
| --- | --- | --- |
| 按下高亮 | **pointerdown**（不是 click） | `:active` 样式立即生效 |
| 加载态 | 请求发出瞬间 | 按钮内联 spinner + 禁用 |
| 提交成功 | 响应返回后 | Toast 从底部滑入（弹簧） |
| 校验错误 | **失焦或输入时**（不是提交时） | 输入框下方淡入错误文案 + 红色描边 |
| 删除确认 | 点击删除瞬间 | 确认对话框（模态层） |
| 拖拽中 | 持续 1:1 跟手 | 直接设置 transform，无动画 |
| 数据更新 | 响应后 | 列表项高亮 800ms 后淡出 |

> **黄金法则**：反馈必须在 **100ms 内**可见。任何超过 100ms 的等待都会被感知为"卡"。

### 8.5 动效时长速查（CSS 过渡类）

| 过渡 | 时长 | 缓动 |
| --- | --- | --- |
| 颜色 / 背景 / 透明度 | 150ms | `ease-out` |
| 小幅位移（≤8px） | 150ms | `ease-out` |
| 阴影 | 200ms | `ease-out` |
| 中幅位移 / 尺寸 | 250ms | `cubic-bezier(.32,.72,0,1)`（苹果常用） |
| 主题切换（全局色变） | 200ms | `ease` |

> **注意**：主题切换时不要给 `*` 加全局 transition（会连带触发所有元素动画，性能灾难）。只给需要变色的容器加过渡，或直接瞬时切换。

### 8.6 降级：reduced motion

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 200ms !important;   /* 保留极短过渡，保留可感知性 */
    scroll-behavior: auto !important;
  }

  /* 手势驱动改为淡入淡出 */
  .sheet { transition: opacity 200ms ease; transform: none !important; }
}
```

**降级不是"没有动效"**：保留透明度与颜色变化（帮助理解状态变化），去掉位移、缩放、弹性。

```css
@media (prefers-reduced-transparency: reduce) {
  .toolbar, .sidebar, .sheet {
    background: var(--color-surface-raised);
    backdrop-filter: none;
    -webkit-backdrop-filter: none;
  }
}

@media (prefers-contrast: more) {
  :root {
    --color-separator: var(--gray-500);
    --color-text-secondary: var(--gray-700);
  }
  .card { border: 1px solid var(--color-separator-opaque); }
}
```

## 11. 无障碍

### 11.1 通用要求

| 项 | 要求 |
| --- | --- |
| 对比度 | 见 §3.4 |
| 键盘可达 | 所有交互元素可 Tab 到达；焦点顺序与视觉顺序一致 |
| 焦点可见 | `:focus-visible` 2px 强调色 + 2px 偏移，**不得** `outline: none` |
| 语义标签 | 使用 `<button>` `<nav>` `<main>` `<h1-h6>` 等原生标签；必要时加 ARIA |
| 图标按钮 | 必须有 `aria-label`（中文描述） |
| 表单 | `<label for>` 与输入关联；错误用 `aria-describedby` 关联 |
| 动态内容 | 重要变化用 `aria-live="polite"` 播报（如"已保存"） |
| 触控尺寸 | ≥ 44×44pt |
| 图片 | 附件缩略图有 `alt`（用文件名或分类描述） |
| 动效 | 尊重 `prefers-reduced-motion`（见 §8.6） |
| 缩放 | 支持 200% 缩放不破版；用 `rem` 而非 `px` 定义字号 |

### 11.2 键盘快捷键

| 快捷键 | 动作 |
| --- | --- |
| `⌘K` / `Ctrl+K` | 全局搜索 |
| `N` | 新建档案 |
| `⌘\` | 切换侧栏 |
| `⌘⇧D` | 切换深浅色主题 |
| `?` | 快捷键帮助 |

| `↑↓` | 列表中移动选择 |
| `Enter` | 打开选中条目 |

> 快捷键在输入框聚焦时**不生效**（除 `Esc`）。

### 11.3 焦点管理

| 场景 | 行为 |
| --- | --- |
| 打开 Sheet | 焦点移到 Sheet 首个可聚焦元素；`Esc` 关闭 |

| 路由跳转 | 焦点移到主内容区标题，并播报 |

## 12. 暗色模式专项

### 12.1 暗色不是"反色"

| 常见错误 | 正确做法 |
| --- | --- |
| 纯黑背景 `#000` | 用 `#0a0a0b`（略带灰的黑），降低对比疲劳 |
| 阴影变浅 | 阴影**加深**（深色背景上阴影视觉衰减） |
| 饱和度不变 | 强调色在暗色下**降饱和、提亮**（`#0071e3` → `#64a8ff`） |
| 图片不变 | 图片可略微降低亮度避免刺眼（`filter: brightness(.92)`），但证件照需保真 → **不加滤镜** |
| 纯白文字 | 用 `rgba(255,255,255,.92)` 而非 `#fff`，降低眩光 |

### 12.2 关键对比（证件照场景）

证件照片是**深色模式下的重灾区**：白底证件照在暗色页面中会形成刺眼亮块。

| 方案 | 做法 |
| --- | --- |
| 证件照容器 | 浅色主题下容器保持白底（`--color-surface-raised` 不用），证件照不变色 |
| 深色模式证件照 | 容器使用 `#f5f5f7`（浅灰白）而非纯黑，保证照片边缘可见 |
| 缩略图 | 统一加 `border-radius` + 1px `--color-separator` 边框，与背景分离 |

> **决策**：证件/证书类照片在两种主题下都使用**浅色容器底**。这是有意的例外 —— 保真优先于统一。

### 12.3 主题切换体验

| 要求 | 实现 |
| --- | --- |
| 无闪烁 | `<head>` 内联同步脚本（见 §2.3） |
| 过渡自然 | 200ms 颜色过渡，不做布局动画 |
| 用户选择持久化 | `localStorage['ams.theme']` = `light`/`dark`/`system` |
| 跟随系统 | 默认 `system`；用户显式选择后不再跟随（除非选 `system`） |
| 系统变化响应 | `matchMedia('(prefers-color-scheme: dark)').addEventListener('change')`（**必须保存监听器以便清理**） |
